Lanai-Anggun-Event-Space-Booking-System

My Bachelor's Degree Final Year Project. Wedding Hall Booking System where users can choose package, date, and halls. Admins and Owners can make changes using CMS.
Features

    Hall Booking System: Allows users to select a package, date, and time for booking.
    Payment Integration: Supports payments using credit cards.
    Admin and Owner CMS: Admins and owners can manage bookings and make changes through a Content Management System (CMS).
